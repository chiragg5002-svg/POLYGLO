Developer Platform (DBaaS)

Create projects, issue API keys and see where MAESTRO stored each collection. Your applications talk to /v1/data, /v1/collections and /v1/query with Authorization: Bearer pk_… — see DBaaS.md.

Set MAESTRO_ADMIN_TOKEN in the project’s .env and restart the API. Operator tokens are never printed in logs. The token is masked and held in this tab’s session storage; it is never placed in URLs.
